# Neuron Device Runtime

The **on-device agent** that runs on a Raspberry Pi (5 / 4 / Zero 2 W) or
the future MicroPython port for Pico 2 W. Reads the firmware bundle
generated by the Master Platform's wizard build (`DNA-XXXX-XXXX.zip`)
and translates it into live device behaviour.

This is the **child** side of the parent-only communication contract:
the agent opens persistent outbound channels to its parent and refuses
all inbound connections (the install script writes an `nftables`
deny-all on input). All commands arrive over the established mTLS
session.

## What the agent does

1. **Boot.** On startup, mounts `/boot/neuron/` and reads:
   - `dna.json` — identity, parent, asset id, location, fingerprint
   - `brain.json` — channels, heartbeat, safety interlocks, rules,
     network_policy, telemetry config
   - `wifi.json` — primary + secondary WiFi profiles (already applied
     to `wpa_supplicant.conf` by `install.sh` at first boot, kept here
     for re-application on roaming).
   - `vendor_accounts.json` — Tapo / Hue / Nest / Ring etc. creds
     (decrypted at master-build time; the agent uses them to drive
     smart-home gear over WiFi).
2. **Auto-populate UUID.** If `dna.json["device_dna"]` is the wizard's
   placeholder, hash `cpuid + eth0_mac` and write it back. Report to
   parent.
3. **Open channels:**
   - `command_and_control` (mTLS to parent — recipe commands, twin
     updates, telemetry uploads).
   - `emergency` (separate cert, allowed_commands =
     {safe_stop, safe_shutdown, status} — always reachable).
   - `ota` (HTTPS pull for base-firmware / app-bundle / config
     updates).
4. **Heartbeat.** Bidirectional — child → parent every
   `heartbeat.child_to_parent_ms`; the parent's heartbeats are
   monitored. When the parent's heartbeat is missing for
   `default_disconnect_grace_seconds`, the agent flips into
   **autonomous mode** and enforces failsafes locally.
5. **Safety interlocks.** Each `ComponentInstance.failsafe_action` is
   wired into a per-pin watchdog. If the agent loses the parent link
   AND a watchdog fires AND the rule is `critical`, the brain enforces
   the action locally without asking anyone.
6. **Local rules** (IF → THEN). Same engine as interlocks but operator-
   authored — `Temp > 80 → stop_motor` etc. Evaluated every sample
   interval against latest telemetry.
7. **Telemetry.** Samples enabled channels (`cpu`, `memory`,
   `temperature`, `disk`, …) at the configured interval and publishes
   to MQTT under `factory/<f>/<line>/<machine>/telemetry`.

## File layout

```
device_runtime/
├─ README.md
├─ requirements.txt
└─ neuron_agent/
   ├─ __init__.py
   ├─ __main__.py           entry point — python3 -m neuron_agent
   ├─ bundle.py             reads /boot/neuron/*.json
   ├─ identity.py           UUID auto-population from hardware ID
   ├─ channels.py           MQTT C&C + emergency + OTA
   ├─ heartbeat.py          bidirectional heartbeat loop
   ├─ safety.py             interlocks + rules + failsafe enforcement
   ├─ telemetry.py          per-channel samplers
   ├─ gpio.py               thin abstraction over RPi.GPIO / gpiozero / mock
   └─ network_policy.py     applies nftables deny-all + SSH-off-at-boot
```

## Running it

On the device (Pi):

```bash
sudo /opt/neuron/install.sh /tmp/DNA-XXXX-XXXX.zip
sudo systemctl status neuron-agent.service
journalctl -u neuron-agent.service -f
```

For local development (no Pi):

```bash
python3 -m neuron_agent --bundle ./test_bundle/ --mock-gpio --insecure
```

The `--insecure` flag opens plain MQTT instead of mTLS (for testing
against a local mosquitto). Production never runs `--insecure`.

## Hard rules (must not violate)

- **Outbound only.** The agent never binds a listening socket.
  `network_policy.json` is applied by `install.sh` before the agent
  ever starts.
- **SSH disabled at boot.** Parent re-enables on demand via reverse
  tunnel.
- **Local enforcement of `critical` rules.** When the parent link is
  alive, the brain still enforces a `critical: true` rule itself — the
  parent is advisory for these.
- **Fail-closed on safety doubt.** If the bundle parses but
  fingerprint_sha256 doesn't verify, the agent refuses to start.
