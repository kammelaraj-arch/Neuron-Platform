Pi-side install — shown once

Run this on the Pi to install the pull-agent. The token below is the only auth material — copy this whole block now. 

cd /tmp && \
git clone --depth 1 https://github.com/kammelaraj-arch/Neuron-Platform.git neuron-tmp && \
sudo bash neuron-tmp/apps/neuron-agent/install.sh && \
sudo tee /etc/default/neuron-agent >/dev/null <<'ENV'
NEURON_MASTER_URL={{ public_base }}
NEURON_DEVICE_ID={{ one_time_agent_token.device_id }}
NEURON_AGENT_TOKEN={{ one_time_agent_token.token }}
NEURON_LOCAL_BASE=http://127.0.0.1:5001
ENV
sudo systemctl restart neuron-agent
sudo journalctl -u neuron-agent -f

Once the agent connects (you'll see neuron-agent online in the journal), it polls every few seconds. Voice → Alexa scene → queued command → next poll picks it up.
