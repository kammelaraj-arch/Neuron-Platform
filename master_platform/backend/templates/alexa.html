Step 2 · Smart Home Skill endpoint

Alexa Smart Home Skills require AWS Lambda as the directive endpoint — they don't POST to arbitrary URLs directly. Create a tiny Lambda (Node.js or Python) in the same AWS account that's signed in as {{ default_email }}, paste the snippet below as its handler, and put the Lambda ARN into the skill's Endpoint field.

The Lambda's only job is to forward the directive envelope to:

{{ public_base }}/api/alexa/directive
Show Lambda handler (Python 3.11) 
import json, os, urllib.request

NEURON_URL = "{{ public_base }}/api/alexa/directive"

def lambda_handler(event, context):
    req = urllib.request.Request(
        NEURON_URL,
        data=json.dumps(event).encode("utf-8"),
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=8) as r:
        return json.loads(r.read())

Step 3 · what voice commands you'll get

Once linked, Alexa will discover every Tado zone and Ring device Neuron knows about. Examples:

  • “Alexa, set <zone-name> to 21 degrees” → Tado setpoint
  • “Alexa, turn off <zone-name>” → Tado zone OFF (frost protection)
  • “Alexa, turn on <camera-name>” → Ring floodlight ON
  • “Alexa, arm <alarm-name> in away mode” → Ring alarm hub AWAY
  • “Alexa, disarm <alarm-name>” → Ring alarm hub disarm
