🌐 Browser-only auto-scan

Runs entirely in your browser, no terminal, no install. Uses WebRTC to detect your laptop's local IP, then HTTP-probes every address on the same subnet to find live devices (Pis, IP cameras, NVRs, routers, anything answering on port 80). Optionally also scans BLE devices nearby via Web Bluetooth.

⚠ WiFi SSID enumeration is not available to web browsers (security restriction across all major browsers — no JS API exists). For SSID list use the Edge or CLI tabs.

Click "Auto-scan LAN" to begin.

💻 Scan from this device

⚠ Browsers cannot scan WiFi directly — a hard security restriction in Chrome / Firefox / Safari / Edge (no JS API exists). The "client-side" scan works by running a tiny shell command in YOUR laptop's terminal that does the scan and uploads the result here.

Workflow: (1) copy the command below, (2) paste into a terminal on your laptop (Linux / macOS / WSL), (3) wait ~5 seconds, (4) click "🔄 Load latest client scan" to see the result.
▾ How to run it — one-line copy/paste

On Linux / macOS / WSL: open a terminal on your laptop and paste this. (Replace <API_KEY> with an integration-tier API key from /ui/secrets.) 

bash <(curl -fsSL https://{{ request.url.hostname }}/static/neuron-client-scan.sh) \
  --group https://{{ request.url.hostname }}/api/wizard/{{ group.id }}/client-scan \
  --secret <API_KEY>

The script auto-detects your OS, runs nmcli / airport / iwlist for WiFi, and nmap / arp -a for devices, then POSTs the JSON to this wizard. Refresh / click "Load latest" below to see results.
